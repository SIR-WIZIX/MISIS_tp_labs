# Реализация структуры классов

## include 
Файлы заголовков для проекта

## src 
Файлы с реализациями классов

## MakeFile
Сборка итогового проекта с небольшим PoC описана через предварительную компиляцию отдельных объектов в ```.o``` и ```.d```. После чего связывание бинарников в ```build/poc```

```bash
$ make
```
Для сборки проекта

## make build

```bash
$ make build
```
Создает директорию ```build```

## make run 

```bash
$ make run
```
Собирает проект при необходимости и запускает ```build/poc```

## make clean

```bash
$ make clean
```
Очищает ```build```
