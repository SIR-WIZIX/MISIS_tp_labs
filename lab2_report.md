## Реализация структуры классов

Лабораторная работа выполнена на C++17 в директории `lab2`.

Объявления классов находятся в `include`, реализации — в `src`. Интерфейсы `Attacker` и `Moveable` определены только в заголовках.

`GameObject` хранит идентификатор, имя и координаты объекта. От него наследуются `Unit` со здоровьем и `Building` с состоянием постройки. От `Unit` наследуется `Archer`, от `Building` — `Fort` и `MobileHouse`.

Поля классов закрыты через `private`. Для изменения координат наследниками предусмотрен `protected`-метод `setPosition`.

`Attacker` задаёт метод атаки, `Moveable` — метод перемещения. Они реализованы как абстрактные классы с чисто виртуальными методами. Лучник реализует оба интерфейса, крепость — только атаку, передвижной дом — только перемещение.

Вызовы через ссылки на интерфейсы демонстрируют полиморфизм. Метод `attack` принимает цель по ссылке, поэтому изменяет здоровье исходного объекта.

## Сборка и запуск

Для сборки проекта используется Makefile.

```bash
cd lab2
make
make run
```

Файлы `.cpp` компилируются в объектные файлы `.o`. Дополнительно создаются `.d` с зависимостями от заголовков. Объектные файлы связываются в исполняемый файл `build/poc`.

Результат выполнения PoC:

```text
Target HP: 70
Archer: 3, 4
House: 6, 7
```

Лучник наносит цели 10 единиц урона, крепость — 20. Здоровье цели уменьшается со 100 до 70. Лучник перемещается в координаты `(3, 4)`, передвижной дом — в `(6, 7)`.
